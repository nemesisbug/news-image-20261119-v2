A one-page newspaper front page that sums up Thursday 19 November 2026 in 42 verified stories — three hero stories, twelve secondary cards, a day-by-hours timeline, a stat strip, a hand-drawn world map with numbered pins, a verdict box, markets, and a date-check footer that names the headlines deliberately left off because they are not 19 November news. The image is drawn in code by build_image.py (Python + PIL, standard library plus Pillow for rendering) and copied to the output directory by main.py.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
